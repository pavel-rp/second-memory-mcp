## What this file does not establish

- **That any threat modelled here has occurred.** Every row describes what the deployment *permits*,
  read off the code and the platform facts at `57aeba3`. No event is asserted.
- **That the enumeration is complete over paths that exist.** It is complete over paths that enter
  `IN-1` … `IN-8`. `F-S12-5` records the one shape no reading of this repository can close, and it is
  a blocking finding rather than a caveat.
- **That the operator has done anything.** §5 models a path. Naming a path is not an allegation, and
  the section says so in its own framing paragraph rather than leaving the reader to infer it.
- **That `NEU-895` will accept the amendment.** It is routed under trigger 3 with a suggested shape.
  The record's owner may amend it differently, or reject it.
- **No QA pass.** The `qa-execution` surface is unconfigured, so the automated QA phase is a genuine
  Core Article 8 no-op. This sub-task cites **`F-S11-5`** for that position rather than `CAP-S1-3`,
  because SUB-11 established that `CAP-S1-3` has no register entry at all.
